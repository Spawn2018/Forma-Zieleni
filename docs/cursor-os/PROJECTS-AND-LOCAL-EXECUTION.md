# Cursor Projects and local execution

## Cursor Projects
Use a Cursor Project for work that spans multiple slices or weeks. The coordinator plans/delegates; implementation agents write code. Project context must still defer to the version-controlled Forma Zieleni canon.

Projects are cloud-first. Do not assume every local-only tool or credential is available to a Project agent.

## Local execution
For ordinary development, open the repository in Cursor and use Agent/Plan modes. Cursor CLI may be installed for terminal automation. My Machines can be enabled later when there is a concrete benefit from running Cloud Agent tool calls against this computer's checkout/state.

My Machines is not required to start building Forma Zieleni. Do not expose production secrets merely to make agent execution convenient.

## Git policy
The owner chose direct work on `main`. Keep changes small and checkpointed. The absence of PRs increases the importance of the pre-push gate, independent review and clean commits. Never push automatically merely because implementation finished.
