# Staff project next milestone

Status: contracted for `ADMIN-PROJECT-NEXT-MILESTONE` / `FZ-REQ-ADMIN-042`.

## Surface

A staff project names the earliest open milestone already loaded for that
project. The line includes the title, the Polish status, and the due
instant in Polish UTC words. A milestone with no due says `bez terminu`.

A done milestone is skipped. Another project’s milestone stays off the
row. A failed or forbidden milestone read is not shown as no milestone.
An empty milestone list is `Otwarte kamienie milowe: brak`.

## Out of scope

- A new milestone field.
- Payment, signing, and a stored sort.
- DNS, Cloudflare, deploy, and live customer data.
