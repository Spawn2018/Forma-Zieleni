# Staff site order

Status: contracted for `ADMIN-SITE-ORDER` / `FZ-REQ-ADMIN-052`.

## Surface

The staff site list orders records by the earlier recorded instant.
The same instant stays in id order. Every record stays on the list.

## Out of scope

- A new timestamp field or a stored sort.
- Price, payment, and signing.
- DNS, Cloudflare, deploy, and live customer data.
