# Staff milestone status labels

Status: contracted for `ADMIN-MILESTONE-LABELS` / `FZ-REQ-ADMIN-056`.

## Surface

A staff milestone shows its status in Polish: zaplanowany, w toku, or
zrobiony. An unknown status token rejects the list. The raw token is
not shown. The status post still sends the machine token.

## Out of scope

- A new status or a stored translation.
- Prices, payment, and signing.
- DNS, Cloudflare, deploy, and live customer data.
