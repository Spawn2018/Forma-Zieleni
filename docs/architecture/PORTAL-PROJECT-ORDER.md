# Client project order

Status: contracted for `PORTAL-PROJECT-ORDER` / `FZ-REQ-PORTAL-033`.

## Surface

The client project list orders projects by the earlier recorded instant.
The same instant stays in id order. Every project stays on the list.

## Out of scope

- A new timestamp field or a stored sort.
- Price, payment, and signing.
- DNS, Cloudflare, deploy, and live customer data.
