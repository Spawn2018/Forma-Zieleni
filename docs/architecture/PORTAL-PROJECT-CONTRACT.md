# Portal project contract

Status: contracted for `PORTAL-PROJECT-CONTRACT` / `FZ-REQ-PORTAL-018`.

## Surface

A client project card names the contract already stored on that project:
`Umowa: <id>`. The id is the opaque contract id the project list already
mapped. Another project’s contract stays on that other card.

A blank contract id fails the project list map. The card does not invent
a contract title, a price, or a signature.

The separate contract list stays.

## Out of scope

- A new project or contract store.
- Payment, signing, and a contract document.
- DNS, Cloudflare, deploy, and live customer data.
