# Staff contract projects

Status: contracted for `ADMIN-CONTRACT-PROJECT` / `FZ-REQ-ADMIN-048`.

## Surface

A staff contract names the projects already loaded for that contract. One
project is `Projekt: <id>`. Several projects are `Projekty: <id>, <id>` in
id order. Another contract’s project stays off the row. A failed or
forbidden project read stays a failed or forbidden read.

## Out of scope

- A new project, price, payment, or signature.
- DNS, Cloudflare, deploy, and live customer data.
