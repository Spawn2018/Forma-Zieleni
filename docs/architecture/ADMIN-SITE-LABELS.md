# Admin site labels

Status: contracted for `ADMIN-SITE-LABELS` / `FZ-REQ-ADMIN-028`.

## Surface

Staff see Polish words for the closed observation kinds: spadek,
ukształtowanie, gleba, nasłonecznienie, wystawa, otoczenie, klimat.
The select still posts the machine kind (`slope`, `topography`, `soil`,
`sun`, `aspect`, `surroundings`, `climate`).

A site record shows `reguły` instead of the stored `RULES` token. The list
map already rejects any other stage, so an unknown token is not printed.

## Out of scope

- A new observation kind or a new stage.
- A change to RULES codes, findings, or the observation post body.
- Payment, signing, a digital twin, and live third-party data.
- DNS, Cloudflare, deploy, and live customer data.
