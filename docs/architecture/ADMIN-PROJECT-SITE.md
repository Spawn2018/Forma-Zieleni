# Staff project site count

Status: contracted for `ADMIN-PROJECT-SITE` / `FZ-REQ-ADMIN-046`.

## Surface

A staff project card counts the site constraints and opportunities already
loaded for that project. Every loaded record for the project is included.
Another project’s findings stay off the card. A failed or forbidden site
read stays a failed or forbidden read.

## Out of scope

- A new site record, observation, or stored count.
- Finding codes, prices, payment, and signing on the project card.
- DNS, Cloudflare, deploy, and live customer data.
