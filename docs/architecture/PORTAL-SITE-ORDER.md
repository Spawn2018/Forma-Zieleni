# Client site order

Status: contracted for `PORTAL-SITE-ORDER` / `FZ-REQ-PORTAL-029`.

## Surface

The client site list orders site records by the earlier recorded instant.
The same instant stays in id order. Every site record stays on the list.

## Out of scope

- A new timestamp field or a stored sort.
- Finding codes, prices, payment, and signing.
- DNS, Cloudflare, deploy, and live customer data.
