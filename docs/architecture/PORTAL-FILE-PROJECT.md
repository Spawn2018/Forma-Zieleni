# Portal file project

Status: contracted for `PORTAL-FILE-PROJECT` / `FZ-REQ-PORTAL-025`.

## Surface

A portal file row names the project id already stored on that file. Another
file’s project stays off the row. A blank project id fails the list map.

The project card still lists that project’s files by name. This row only
adds the id the file already carries.

## Out of scope

- A new file field or a stored display label.
- Filtering the file list.
- Payment, signing, and a storage provider.
- DNS, Cloudflare, deploy, and live customer data.
