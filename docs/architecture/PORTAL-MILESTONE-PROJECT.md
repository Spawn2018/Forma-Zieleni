# Portal milestone project

Status: contracted for `PORTAL-MILESTONE-PROJECT` / `FZ-REQ-PORTAL-020`.

## Surface

A client milestone row names the project already stored on that milestone:
`projekt <id>`. Another milestone’s project stays on that other row.

A blank project id fails the milestone list map. The row does not invent
a project title.

The separate project list stays.

## Out of scope

- A new milestone or project store.
- Payment, signing, and a decision log.
- DNS, Cloudflare, deploy, and live customer data.
