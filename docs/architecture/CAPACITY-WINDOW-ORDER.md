# Capacity window order

Status: contracted for `CAPACITY-WINDOW-ORDER` / `FZ-REQ-ADMIN-040`.

## Surface

The staff capacity list orders windows by earlier start. The same start
stays in id order. A closed window stays on the list.

## Out of scope

- A new window field or a stored sort.
- An external calendar.
- Payment, signing, and a promised-term decision.
- DNS, Cloudflare, deploy, and live customer data.
