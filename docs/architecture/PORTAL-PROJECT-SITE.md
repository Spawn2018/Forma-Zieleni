# Portal project site

Status: contracted for `PORTAL-PROJECT-SITE` / `FZ-REQ-PORTAL-017`.

## Surface

Each portal project card counts the site constraints and opportunities
already loaded for that project. A record of another project stays off
the card. When the site list is empty or this project has no record, the
card says **Teren: brak**. When the site read fails or is forbidden, the
card says so and does not pretend the list is empty.

The separate site list stays. No new store or route. Codes and notes stay
on that list; the card does not invent a conclusion from them.

## Out of scope

- A new site observation or a rules change.
- Payment, signing, and staff mutation from the portal.
- DNS, Cloudflare, deploy, and live customer data.
