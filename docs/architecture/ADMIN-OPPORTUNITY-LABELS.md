# Staff opportunity status label

Status: contracted for `ADMIN-OPPORTUNITY-LABELS` / `FZ-REQ-ADMIN-051`.

## Surface

A staff opportunity shows its status in Polish. The only status is
`open`, labeled `otwarta`. An unknown status token rejects the list. The
raw token is not shown.

## Out of scope

- A new opportunity status, price, or probability.
- DNS, Cloudflare, deploy, and live customer data.
