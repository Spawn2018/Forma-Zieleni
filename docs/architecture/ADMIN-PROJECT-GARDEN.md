# Staff project garden

Status: contracted for `ADMIN-PROJECT-GARDEN` / `FZ-REQ-ADMIN-044`.

## Surface

A staff project names the gardens already loaded for that project. Another
project’s garden stays off the row. More than one garden is listed in id
order.

A failed or forbidden garden read is not shown as no garden. An empty
garden list is `Ogród: brak`.

## Out of scope

- A new garden field or a digital twin.
- Payment, signing, and a live inventory.
- DNS, Cloudflare, deploy, and live customer data.
