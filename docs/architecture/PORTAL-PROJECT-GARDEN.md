# Portal project garden

Status: contracted for `PORTAL-PROJECT-GARDEN` / `FZ-REQ-PORTAL-016`.

## Surface

Each portal project card names the garden already loaded for that project.
A garden of another project stays off the card. When the garden list is
empty or this project has no garden, the card says **Ogród: brak**. When
the garden read fails or is forbidden, the card says so and does not
pretend the list is empty.

The separate garden list stays. No new store or route.

## Out of scope

- A live garden, a digital twin, or a sensor feed.
- Payment, signing, and staff mutation from the portal.
- DNS, Cloudflare, deploy, and live customer data.
