# Client contract order

Status: contracted for `PORTAL-CONTRACT-ORDER` / `FZ-REQ-PORTAL-032`.

## Surface

The client contract list orders contracts by the earlier recorded instant.
The same instant stays in id order. Every contract stays on the list.

## Out of scope

- A new timestamp field or a stored sort.
- Price, payment, and signing.
- DNS, Cloudflare, deploy, and live customer data.
