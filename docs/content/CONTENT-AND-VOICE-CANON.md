# Forma Zieleni — Content & Voice Canon

Status: **CURRENT / BINDING**

## Purpose
All customer-facing copy must sound like a real Polish landscape-architecture practice and must be grounded in verified Forma Zieleni facts. Cursor must not fill gaps with generic AI marketing copy.

## Voice
- Polish by default for Polish customer surfaces.
- Direct, calm, concrete and useful.
- Address the customer consistently on “Ty” where the established customer voice does so.
- Prefer nouns, verbs, measurements, deliverables and consequences over promotional adjectives.
- Use landscape-architecture vocabulary correctly: projekt ogrodu, konsultacja, koncepcja, projekt kompleksowy, realizacja, rabata, nasadzenia etc.
- Botanical Latin is used when it adds real professional meaning, not as decoration.

## Prohibited AI-slop patterns
Do not generate unsupported phrases such as:
- “kompleksowe rozwiązania dopasowane do Twoich potrzeb”;
- “z pasją tworzymy wyjątkowe przestrzenie”;
- “innowacyjne podejście” without a concrete explanation;
- “najwyższa jakość”, “lider”, “eksperci”, “premium”, “bezkonkurencyjny” without verified evidence;
- fake urgency, fake scarcity, fake social proof;
- invented reviews, ratings, awards, years, project counts, prices, deadlines, qualifications or partner claims;
- filler sections written only because a template contains them.

No exclamation-mark-heavy sales voice. No vague CTA such as “Dowiedz się więcej” when a concrete action can be named.

## Facts and placeholders
Legacy copy decks are a **content source/reference**, not automatic factual truth. Values such as prices, ratings, review counts, turnaround times, number of projects, awards, geographic coverage and credentials must be verified against current business data before publication.

If a required fact is missing:
1. do not invent it;
2. use an explicit typed/content placeholder in development only when necessary;
3. surface it as a content decision/data requirement;
4. production gate must reject unresolved factual placeholders.

## CTA rule
CTA starts with an action and tells the user what happens next. Use the same name for the same action across the journey.

## Evidence rule
Real project evidence beats adjectives. Prefer: what was the site/problem, what was designed, what changed, what the client received, what can be shown. Testimonials require authentic source/permission as applicable.

## Content review test
Before accepting generated copy ask:
- Is every factual claim sourced?
- Could this paragraph appear unchanged on 100 other agency websites? If yes, rewrite or remove it.
- Does it help the customer understand a decision, deliverable, process or next action?
- Does it use the vocabulary of Forma Zieleni rather than generic marketing language?
- Is it shorter without losing useful information?
