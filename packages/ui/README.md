# packages/ui

Współdzielone komponenty i primitive UI dla aplikacji webowych.

## Odpowiedzialność

- spójny język wizualny dla `web`, `portal` i `admin`,
- komponenty dostępne (accessibility-first),
- bez logiki biznesowej i bez bezpośredniego dostępu do danych.

## Status

Szkielet pakietu. Zależności UI nie zostały jeszcze zainstalowane.
