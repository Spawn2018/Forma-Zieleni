# packages/config

Współdzielona konfiguracja narzędzi monorepo.

## Odpowiedzialność

- wspólne ustawienia TypeScript, lint, formatowania i jakości kodu,
- spójne baseline’y dla `apps/*` i `packages/*`,
- bez logiki domenowej.

## Status

Szkielet pakietu. Konfiguracje narzędzi zostaną dodane w kolejnych etapach.
