# dependency-review
Require a concrete use case. Check maintenance/activity, license compatibility, security history/advisories, transitive dependency weight, bundle/runtime cost, API stability, ecosystem fit and exit/replacement cost. Prefer no dependency when platform capabilities are adequate. Record the decision when dependency impact is architectural or operational.
