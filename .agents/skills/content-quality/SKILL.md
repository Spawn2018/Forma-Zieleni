Read `docs/content/CONTENT-AND-VOICE-CANON.md` and current product/domain docs. Legacy `03-COPY.md` is reference input, not permission to publish stale facts.

Never invent prices, counts, reviews, ratings, awards, credentials, timelines, availability, partner terms or project outcomes. Mark missing factual input instead.

Reject generic agency language. Copy must be concrete, useful, concise, Polish, domain-aware and tied to a real user action or evidence. Run the anti-slop content review before completion.
