# apps/admin

Panel administratora i UI operacyjne (CRM / Revenue OS).

## Odpowiedzialność

- zarządzanie leadami, sprzedażą, projektami i płatnościami,
- konfiguracja procesów wewnętrznych,
- operacje wymagające uprawnień personelu Forma Zieleni.

## Status
