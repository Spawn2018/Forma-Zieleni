# professional-code
Read docs/engineering/ENGINEERING-STANDARD.md and REFACTORING-POLICY.md.

Before editing, identify the responsibility, domain vocabulary, existing local patterns and smallest coherent change. Prefer explicit code, minimal dependencies and existing abstractions. After editing, remove accidental complexity, duplication, stale comments, dead code, placeholders and needless wrappers. Do not conceal AI authorship; make the code professionally maintainable.
