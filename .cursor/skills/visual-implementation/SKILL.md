name: visual-implementation
description: Implement or review Forma Zieleni UI without generic AI design. Use for any web, portal, admin, mobile or Garden OS visual work.
---
Read `docs/design/VISUAL-PRODUCT-CANON.md`, `docs/ux/UX-PRODUCT-CANON.md`, `docs/content/CONTENT-AND-VOICE-CANON.md` and the relevant entry in `docs/design/VISUAL-REFERENCE-MAP.md` before editing UI.

Before coding, identify: product surface, user/job, relevant mockup, canonical flow, real content/data, accessibility requirements and performance-sensitive assets.

Do not invent a new brand, generic SaaS layout, fake evidence or filler copy. Preserve the “Plan nasadzeń” identity where appropriate. Prefer authentic photography/domain information over decorative UI.

After implementation perform a visual fidelity self-review, responsive review, keyboard/focus review, reduced-motion review and performance review. Material deviation from current visual direction is DECISION.
