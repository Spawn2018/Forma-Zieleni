# database-engineering
Read docs/engineering/DATABASE-ENGINEERING.md and PERFORMANCE-ENGINEERING.md. Preserve domain invariants and data integrity first. Review query shape, bounds, authorization, concurrency, migration safety and representative execution plans. Do not denormalize, add cache or add indexes by folklore; require workload evidence.
